✦ FAQ

Pertanyaan yang
Sering Ditanyakan

Apakah ada biaya bulanan atau tahunan? ▼
Tidak ada. Sistem web member ini berjalan di infrastruktur cloud yang sudah gratis. Anda hanya bayar biaya jasa deploy sekali saja. Setelah itu, sistem berjalan gratis selamanya tanpa biaya tambahan apapun.
Butuh install aplikasi di HP? ▼
Tidak perlu install apapun. Web member langsung dibuka lewat browser HP (Chrome, Firefox, Safari) ataupun laptop. Scan QR Code menggunakan kamera HP biasa yang sudah ada. Cukup simpan link-nya sebagai shortcut di layar HP.
Berapa lama proses pengerjaannya? ▼
Pengerjaan biasanya selesai dalam 1–3 jam setelah data toko dikirim dan pembayaran dikonfirmasi. Untuk paket custom yang membutuhkan kustomisasi lebih lanjut, bisa 1–2 hari kerja.
Data pelanggan saya aman? ▼
100% aman dan milik Anda sendiri. Data tersimpan di sistem cloud pribadi Anda. Saya selaku penyedia jasa tidak memiliki akses ke data pelanggan toko Anda. Backup otomatis dilakukan secara berkala.
Bisa menampung berapa member? ▼
Secara teknis, sistem dapat menampung hingga ratusan ribu data member. Untuk skala UMKM (ratusan hingga ribuan member), lebih dari cukup dan sistem akan tetap berjalan cepat dan lancar.
Kalau ada error atau butuh bantuan, ada support-nya? ▼
Paket Pro dan Custom sudah termasuk support WhatsApp 30–60 hari. Untuk Paket Starter, saya tetap membantu sejauh kemampuan lewat WA. Sistem sudah stabil dan jarang ada masalah teknis.
Bisa minta fitur tambahan atau custom tampilan? ▼
Bisa! Hubungi saya via WhatsApp untuk diskusi kebutuhan spesifik. Untuk kustomisasi besar (logo, warna, fitur baru) tersedia di Paket Custom dengan harga yang bisa disesuaikan.
